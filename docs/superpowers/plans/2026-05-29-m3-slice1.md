# WorldGen10 M3 — Slice 1: First Rendered Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put real DEM terrain on screen — one clipmap ring mesh displaced by one GPU-computed height page written to a `Texture2dRd` (no readback), sampled in a vertex shader, captured to a PNG that proves visible relief.

**Architecture:** A new `Wg10PageCompute` (gdext) dispatches the M2 hash→grammar→height formula via the **global** RenderingDevice, writing height into an R32F texture exposed as a `Texture2dRd`. A spatial `.gdshader` samples that texture in `vertex()` to displace a flat ring mesh. A minimal slice scene renders one frame and saves a PNG; a gate asserts the frame has real height variance. The M2 crate is unchanged (parity intact); value-correctness leans on the existing M2 parity gate, the new gate proves only the texture→mesh→screen render path.

**Tech Stack:** Rust + godot-rust (gdext 0.5.3, Godot API 4.6); Godot `RenderingDevice` (global, D3D12) + `Texture2dRd` + `RdTextureFormat` (all confirmed present in bindings); a Godot `.gdshader` spatial shader; Godot `SubViewport`/viewport image capture for the PNG; Python gate runner.

**Design source:** `docs/superpowers/specs/2026-05-29-m3-slice1-design.md`. Read it first — especially §2 (the four pillars + the fallback-discipline rule) and §3 (no readback of the height texture).

## Scope & boundaries

**In scope:** render-mode + Texture2dRd-bindable probe (Task 0); `Wg10PageCompute` (compute→R32F `Texture2dRd`, no readback); `height_page.glsl` (imageStore variant of the M2 formula); `ring_displace.gdshader` (vertex samples height tex); the slice scene + PNG capture; the screenshot gate; `m3` gate suite; ROADMAP/STATUS.

**Out of scope (later M3 slices):** page pool, scheduler, multiple rings/morph, recenter, movement, the harness components, the fly-test, the p99<6ms perf gate. Slice 1 is STATIC (one page, one ring, one frame).

## Interface constraints (from design §2 — enforce while building)
1. **No readback of the HEIGHT TEXTURE.** Compute writes it; the vertex shader reads it on-GPU. No `buffer_get_data`/`texture_get_data` of height in the render path. (A one-off COLOUR-FRAME screenshot for the gate is fine — that's verification, not the height path.)
2. **M2 crate unchanged.** `gpu_compute.rs`/`grammar.rs`/`height.rs`/`pack.rs`/`hash.rs`/`npy.rs`/`parity.rs` are NOT modified. `page_compute.rs` is the only new Rust. (M2 parity must stay green — it's the value-correctness proof.)
3. **Config, not magic numbers** (pillar 1): page origin/span/px, ring grid resolution, camera vantage are exported scene vars / a config block — never scattered hardcoded constants.
4. **Fallback discipline** (pillar 4): try the real `Texture2dRd` path first. If it's impractical in gdext 0.5.3, a slice-1-ONLY CPU-fill `ImageTexture` fallback is allowed but MUST be flagged loudly (STATUS + code comment) as "NOT the real path — slice 2 replaces this." Never let it become the foundation.

## Key API facts (confirmed in this repo's gdext bindings)
- `Texture2dRd` (gdext name for Texture2DRD), `RdTextureFormat`, `RdTextureView`, `RenderingDevice`, `SubViewport`, `ImageTexture` all exist in the generated bindings.
- For a texture a SPATIAL MATERIAL can sample, the texture RID must live on the **global** rendering device: `RenderingServer.get_rendering_device()` — NOT a local `create_local_rendering_device()` (M2 used local for parity readback; rendering needs global). `Texture2dRd::set_texture_rd_rid(rid)` wraps a global-RD texture RID into a sampler-bindable Godot texture.
- D3D12 driver; project has NO existing `.tscn` (this is the first scene).

```gdscript
extends SceneTree

# Throwaway probe: (a) does a 3D viewport render to a non-black PNG here, headless?
# (b) can a Texture2dRd (global RenderingDevice R32F texture) be sampled by a
# material? Prints PROBE_RENDER_OK/FAIL + PROBE_TEXRD_OK/FAIL.

func _init() -> void:
	quit(_run())

func _run() -> int:
	# (b) Texture2dRd on the GLOBAL rendering device
	var rd := RenderingServer.get_rendering_device()
	if rd == null:
		print("[probe] PROBE_TEXRD_FAIL reason=no-global-rd")
	else:
		var fmt := RDTextureFormat.new()
		fmt.width = 8
		fmt.height = 8
		fmt.format = RenderingDevice.DATA_FORMAT_R32_SFLOAT
		fmt.usage_bits = (RenderingDevice.TEXTURE_USAGE_SAMPLING_BIT
			| RenderingDevice.TEXTURE_USAGE_STORAGE_BIT
			| RenderingDevice.TEXTURE_USAGE_CAN_UPDATE_BIT)
		var view := RDTextureView.new()
		var rid := rd.texture_create(fmt, view, [])
		if not rid.is_valid():
			print("[probe] PROBE_TEXRD_FAIL reason=texture_create-invalid")
		else:
			var t := Texture2DRD.new()
			t.texture_rd_rid = rid
			print("[probe] PROBE_TEXRD_OK size=%dx%d valid=%s" % [t.get_width(), t.get_height(), str(t.texture_rd_rid.is_valid())])

	# (a) render a simple 3D scene to a SubViewport, save PNG, check non-black
	var vp := SubViewport.new()
	vp.size = Vector2i(64, 64)
	vp.transparent_bg = false
	get_root().add_child(vp)
	var cam := Camera3D.new()
	cam.position = Vector3(0, 1, 3)
	cam.look_at_from_position(Vector3(0, 1, 3), Vector3(0, 0, 0), Vector3.UP)
	vp.add_child(cam)
	var mesh := MeshInstance3D.new()
	mesh.mesh = BoxMesh.new()
	var mat := StandardMaterial3D.new()
	mat.albedo_color = Color(0.2, 0.8, 0.3)
	mat.shading_mode = BaseMaterial3D.SHADING_MODE_UNSHADED
	mesh.material_override = mat
	vp.add_child(mesh)
	var light := DirectionalLight3D.new()
	vp.add_child(light)
	# let it render a few frames
	for i in range(3):
		await process_frame
	var img := vp.get_texture().get_image()
	var nonblack := 0
	for y in range(img.get_height()):
		for x in range(img.get_width()):
			if img.get_pixel(x, y).r > 0.05 or img.get_pixel(x, y).g > 0.05:
				nonblack += 1
	if nonblack > 10:
		img.save_png("res://_m3_probe/probe_render.png")
		print("[probe] PROBE_RENDER_OK nonblack=%d" % nonblack)
		return 0
	print("[probe] PROBE_RENDER_FAIL nonblack=%d (viewport rendered black)" % nonblack)
	return 1
```
NOTE: `Texture2DRD` is the GDScript class name (gdext `Texture2dRd`). `await process_frame` needs the SceneTree's `process_frame` signal — in a SceneTree `_init`, use `await (self as SceneTree).process_frame` if a bare `await process_frame` doesn't resolve; the implementer adjusts to whatever the engine accepts and reports the exact form used.

## Task 1: height_page.glsl — compute writes height to an R32F image

**Files:**
- Create: `wg-10/worldgen_terrain/shaders/height_page.glsl`

The compute shader: same hash→grammar→height formula as `height_field.glsl`, but output is `imageStore` into an R32F `image2D` for a page region, indexed by `gl_GlobalInvocationID.xy`. World coord per texel: `world = origin + (texel + 0.5)/page_px * world_span`.

- [ ] **Step 1: Create the shader.** Create `wg-10/worldgen_terrain/shaders/height_page.glsl`. Copy the ENTIRE body of `wg-10/worldgen_terrain/shaders/height_field.glsl` (all the hash/grammar/height functions — fold_u32, hash_ints*, palette/family/sample_kernel/moderation/etc., and the buffer bindings it needs: Palettes/CompatOff/CompatFlat/KRec/KParam/KData + the Params push constant), with these CHANGES:
  - Replace the per-coord `Coords`/`OutH`/`OutSig` buffer bindings (bindings 0,1,2) with: keep the pack-data bindings (palettes/compat/kernels at their bindings) and ADD an output image binding:
    ```glsl
    layout(set = 0, binding = 0, r32f) restrict writeonly uniform image2D height_img;
    ```
    (Use binding 0 for the output image; shift the pack-data bindings to 1..N to match what page_compute.rs will provide — keep them contiguous and documented. The implementer sets the binding numbers consistently between this shader and page_compute.rs.)
  - Add to the Params push constant: `float origin_x; float origin_z; float world_span; int page_px;` (plus the existing seed + pack table sizes the formula needs).
  - `main()`: 
    ```glsl
    void main() {
        ivec2 px = ivec2(gl_GlobalInvocationID.xy);
        if (px.x >= P.page_px || px.y >= P.page_px) return;
        float u = (float(px.x) + 0.5) / float(P.page_px);
        float v = (float(px.y) + 0.5) / float(P.page_px);
        float wx = P.origin_x + u * P.world_span;
        float wz = P.origin_z + v * P.world_span;
        float h = height_at(wx, wz);   // the shared formula (rename the M2 main body into a height_at(x,z) helper)
        imageStore(height_img, px, vec4(h, 0.0, 0.0, 1.0));
    }
    ```
  - Refactor the M2 shader's main-body height computation into a `float height_at(float x, float z)` function so both shaders call the identical logic. (This is the "factor the shared formula" decision from spec §3 — one source of the math. If a GLSL `#include` is cleanly supported by Godot's importer, prefer that; otherwise duplicate the function with an `// EDIT BOTH SIDES — must match height_field.glsl height_at()` header. The implementer picks based on what Godot's glsl importer accepts and reports which.)
  - `layout(local_size_x = 16, local_size_y = 16) in;` (2D dispatch for a page).

## Task 3: ring_displace.gdshader — vertex displacement from the height texture

**Files:**
- Create: `wg-10/worldgen_terrain/shaders/ring_displace.gdshader`

A spatial shader: `vertex()` maps local XZ to the page UV, samples the height texture, sets `VERTEX.y`. `fragment()` colors by height so relief is legible.

- [ ] **Step 1: Create the shader.** Create `wg-10/worldgen_terrain/shaders/ring_displace.gdshader`:
```glsl
shader_type spatial;
render_mode unshaded, cull_disabled;

uniform sampler2D height_tex;     // the Texture2dRd from Wg10PageCompute (R32F)
uniform float world_span = 8192.0; // page world span (set from config)
uniform float height_scale = 1.0;  // visual amplitude (config; 1.0 = raw metres)
uniform float relief_ref = 2000.0; // for the color gradient normalization

varying float v_height;

void vertex() {
	// mesh is a flat grid centered at origin spanning [-world_span/2, +world_span/2] in XZ.
	vec2 uv = (VERTEX.xz / world_span) + vec2(0.5);
	float h = texture(height_tex, uv).r;
	v_height = h;
	VERTEX.y = h * height_scale;
}

void fragment() {
	// color by height so relief is visible in the PNG (legible, not pretty).
	float t = clamp(v_height / relief_ref * 0.5 + 0.5, 0.0, 1.0);
	ALBEDO = vec3(t, t * 0.8 + 0.1, 1.0 - t);
}
```

## Task 4: Slice scene + PNG capture (`m3_slice1.gd`)

**Files:**

A SceneTree script: load the DEM pack into `Wg10PageCompute`, compute a page texture, build a flat grid mesh with `ring_displace.gdshader` binding that texture, place a camera, render to a SubViewport, save PNG. Config values are exported consts at the top (pillar 1).

- [ ] **Step 1: Write the slice.** Create `wg-10/worldgen_terrain/m3/m3_slice1.gd` (TABS):
```gdscript
extends SceneTree

# M3 Slice 1: render ONE DEM height page on ONE ring mesh, capture to PNG.
# Config (pillar 1 — no scattered magic numbers):
const PACK_RES_DIR := "res://worldgen_terrain/packs/dem_v1"
const PACK_FILE := "terrain_pack.gate.json"
const GLSL := "res://worldgen_terrain/shaders/height_page.glsl"
const PAGE_ORIGIN := Vector2(0.0, 0.0)   # world origin of the page
const WORLD_SPAN := 8192.0               # page world span (m)
const PAGE_PX := 256                     # height texture resolution
const GRID_RES := 128                    # ring mesh subdivisions
const HEIGHT_SCALE := 1.0
const SEED := 1337
const VIEW_SIZE := Vector2i(640, 480)
const OUT_PNG := "res://worldgen_terrain/tests/m3_slice1.png"

func _init() -> void:
	quit(await _run())

func _run() -> int:
	if not ClassDB.class_exists("Wg10PageCompute"):
		push_error("Wg10PageCompute not registered"); return 1
	var os_dir: String = ProjectSettings.globalize_path(PACK_RES_DIR)
	var os_glsl: String = ProjectSettings.globalize_path(GLSL)
	var pc: Object = ClassDB.instantiate("Wg10PageCompute")
	var err: String = str(pc.call("load_pack_dir", os_dir, PACK_FILE))
	if err != "":
		push_error("pack load failed: %s" % err); return 1
	var tex = pc.call("compute_page", os_glsl, PAGE_ORIGIN.x, PAGE_ORIGIN.y, WORLD_SPAN, PAGE_PX, SEED)
	if tex == null:
		push_error("compute_page returned null"); return 1

	var vp := SubViewport.new()
	vp.size = VIEW_SIZE
	get_root().add_child(vp)
	# ring mesh: flat grid in XZ centered at origin, spanning WORLD_SPAN
	var plane := PlaneMesh.new()
	plane.size = Vector2(WORLD_SPAN, WORLD_SPAN)
	plane.subdivide_width = GRID_RES
	plane.subdivide_depth = GRID_RES
	var mi := MeshInstance3D.new()
	mi.mesh = plane
	var mat := ShaderMaterial.new()
	mat.shader = load("res://worldgen_terrain/shaders/ring_displace.gdshader")
	mat.set_shader_parameter("height_tex", tex)
	mat.set_shader_parameter("world_span", WORLD_SPAN)
	mat.set_shader_parameter("height_scale", HEIGHT_SCALE)
	mi.material_override = mat
	vp.add_child(mi)
	# camera: above + angled to see relief across the page
	var cam := Camera3D.new()
	var eye := Vector3(WORLD_SPAN * 0.0, WORLD_SPAN * 0.6, WORLD_SPAN * 0.7)
	cam.position = eye
	cam.look_at_from_position(eye, Vector3(0, 0, 0), Vector3.UP)
	cam.far = WORLD_SPAN * 4.0
	vp.add_child(cam)
	var light := DirectionalLight3D.new()
	light.rotation_degrees = Vector3(-50, -30, 0)
	vp.add_child(light)

	for i in range(4):
		await process_frame
	var img := vp.get_texture().get_image()
	img.save_png(OUT_PNG)
	print("[wg10-m3-slice1] captured %s (%dx%d)" % [OUT_PNG, img.get_width(), img.get_height()])
	return 0
```

The implementer adjusts to what Godot 4.6 accepts and reports the exact form. If the Task-0 probe found render is windowed-only, this runs windowed (Task 6's gate handles run-mode).

Simplest + robust: the gate runs the same build-and-render as the slice, then validates the in-memory image:
```gdscript
extends SceneTree

# M3 slice 1 gate: render one DEM page on a ring and assert the frame shows real
# relief (variance present, non-black, finite). Value-correctness is already
# proven by the M2 gpu parity gate (same formula); this proves the render path.

const PACK_RES_DIR := "res://worldgen_terrain/packs/dem_v1"
const PACK_FILE := "terrain_pack.gate.json"
const GLSL := "res://worldgen_terrain/shaders/height_page.glsl"
const WORLD_SPAN := 8192.0
const PAGE_PX := 256
const GRID_RES := 128
const SEED := 1337
const VIEW_SIZE := Vector2i(640, 480)
const MIN_DISTINCT := 8        # at least this many distinct quantized colors -> real relief
const MIN_NONBLACK_FRAC := 0.10

func _init() -> void:
	quit(await _run())

func _run() -> int:
	if not ClassDB.class_exists("Wg10PageCompute"):
		push_error("Wg10PageCompute not registered"); return 1
	if RenderingServer.get_rendering_device() == null:
		print("[wg10-m3-slice1] status=skip reason=no-render-device"); return 2
	var os_dir: String = ProjectSettings.globalize_path(PACK_RES_DIR)
	var os_glsl: String = ProjectSettings.globalize_path(GLSL)
	var pc: Object = ClassDB.instantiate("Wg10PageCompute")
	var err: String = str(pc.call("load_pack_dir", os_dir, PACK_FILE))
	if err != "":
		push_error("pack load failed: %s" % err); return 1
	var tex = pc.call("compute_page", os_glsl, 0.0, 0.0, WORLD_SPAN, PAGE_PX, SEED)
	if tex == null:
		push_error("compute_page null"); return 1

	var vp := SubViewport.new(); vp.size = VIEW_SIZE; get_root().add_child(vp)
	var plane := PlaneMesh.new(); plane.size = Vector2(WORLD_SPAN, WORLD_SPAN)
	plane.subdivide_width = GRID_RES; plane.subdivide_depth = GRID_RES
	var mi := MeshInstance3D.new(); mi.mesh = plane
	var mat := ShaderMaterial.new()
	mat.shader = load("res://worldgen_terrain/shaders/ring_displace.gdshader")
	mat.set_shader_parameter("height_tex", tex)
	mat.set_shader_parameter("world_span", WORLD_SPAN)
	mi.material_override = mat; vp.add_child(mi)
	var cam := Camera3D.new()
	var eye := Vector3(0, WORLD_SPAN * 0.6, WORLD_SPAN * 0.7)
	cam.position = eye; cam.look_at_from_position(eye, Vector3.ZERO, Vector3.UP)
	cam.far = WORLD_SPAN * 4.0; vp.add_child(cam)
	vp.add_child(DirectionalLight3D.new())
	for i in range(4): await process_frame

	var img := vp.get_texture().get_image()
	var distinct := {}
	var nonblack := 0
	var total := img.get_width() * img.get_height()
	for y in range(img.get_height()):
		for x in range(img.get_width()):
			var c := img.get_pixel(x, y)
			if not (is_finite(c.r) and is_finite(c.g) and is_finite(c.b)):
				push_error("non-finite pixel @ %d,%d" % [x, y]); return 1
			if c.r > 0.03 or c.g > 0.03 or c.b > 0.03:
				nonblack += 1
			distinct[Vector3i(int(c.r*16), int(c.g*16), int(c.b*16))] = true
	var frac := float(nonblack) / float(total)
	if distinct.size() < MIN_DISTINCT or frac < MIN_NONBLACK_FRAC:
		push_error("frame lacks relief: distinct=%d nonblack_frac=%.3f" % [distinct.size(), frac])
		print("[wg10-m3-slice1] status=fail distinct=%d nonblack_frac=%.3f" % [distinct.size(), frac])
		return 1
	print("[wg10-m3-slice1] status=pass distinct=%d nonblack_frac=%.3f" % [distinct.size(), frac])
	return 0
```
