# M5 — Detail & masks (design spec)

**Milestone:** M5 (ROADMAP §"Milestone 5 — Detail & masks (GPU, render-only)")
**Status:** design approved (brainstorm), pre-plan.

## 1. Purpose & scope

Add **render-time geometric detail** so the terrain reads as "has real shape,"
addressing the "bare / blobby" look — the biggest single lever per HANDOFF. The
raw DEM kernels lack high-frequency variation; M5 supplies it in the render path
only.

**Framing (owner-steered via the four pillars + "long-term-best worldgen"):**
detail-first scope (pillar-minimal — no unused tooling, perf-guarded), but
**architected as the seam M6/M7 extend, not replace.** The detail layer computes a
small reusable **surface descriptor** (slope / curvature / height-band) that it
consumes now and that M6 (biomes/materials) and M7 (erosion) will reuse. Build
only what detail needs, but build it as that shared seam.

**In scope:**
- Bounded, edge-safe, world-space procedural **detail displacement** in the vertex
  shader.
- A reusable **`surface_descriptor(world)`** (slope, curvature, height_band)
  computed from the base page.
- **Slope-driven modulation** of detail (the rocky↔rolling character knob).
- **LOD fade** so detail vanishes into coarse levels / the geomorph band.
- **Config-driven** tunables (no magic numbers), validated.

**Out of scope (deferred, with reason):**
- **Fragment-normal / lighting detail** → M6 (the shader is currently `unshaded`;
  normal-mapped detail needs lighting). M5 detail is *geometric* and visible now.
- **Standalone world-space mask tooling / debug-mask layer** → M6, where a consumer
  (materials) exists. YAGNI + pillar-2 perf: don't pre-build unused machinery.
- **CPU per-family detail parameters** → M6, where families already drive materials.
- **Tessellation** to carry sub-vertex detail → not now (perf). Sub-vertex detail is
  M6 normal-mapping's job. M5 tunes detail frequency to what the `GRID_RES` mesh can
  carry.
- **Baking detail into the height pages** → REJECTED: pages feed collision bake +
  M8 visible-edits + facts; baking detail there would make detail collidable and
  break the visible-vs-collision contract. Detail stays in `vertex()` only.

## 2. The four pillars (how M5 serves each)

1. **Adaptable/tunable** — every detail parameter is config (amp, freq, octaves,
   gain, slope_influence, slope_ref, per-level fade), validated/clamped, threaded
   through `configure()`. `slope_influence` spans rocky↔rolling without code change.
2. **Performance** — shader-only, no readback, no new GPU pass, no streaming. The
   only new cost is per-vertex ALU + ~4 neighbor page taps for the descriptor. The
   p99 < 6 ms @ ~1000 m/s gate is the LAST slice's sign-off (measure the full cost).
3. **Quality** — detail is **bounded** (closed-form ceiling), **edge-safe** (no
   reopened seams), **LOD-safe** (no morph-boundary pop). No collapse.
4. **No shortcuts** — bad config is validated and rejected (descriptive error), not
   silently defaulted. The descriptor is built as the real reusable seam, not an
   inline hack M6 must rip out.

## 3. Locked technical decisions (from the brainstorm)

- **Domain: vertex displacement (geometric).** Real shape, visible NOW in the
  unshaded view, no front-loading of M6 lighting. Capped by mesh density
  (`GRID_RES`); sub-vertex detail is explicitly M6's job.
- **Source: shader-side procedural fBm** of value-noise (ported to GLSL, mirroring
  the existing `height_field.glsl`/`height_page.glsl` noise lineage). Edge-safe by
  construction (pure function of world position), zero memory/streaming, matches the
  project's deterministic-noise ethos. **Render-only ⇒ no CPU/GPU parity contract on
  the detail itself** (the detail is not a "fact").
- **Structure: surface-descriptor seam (approach B).** A named
  `surface_descriptor(world)` GLSL function = the reusable input M6/M7 extend.
- **Base height is untouched.** Detail is added to `VERTEX.y` *after* the base
  height `h_base` is formed. Facts (`get_height`) and collision read `h_base`.

## 4. Architecture & data flow

All changes live in **`wg-10/worldgen_terrain/shaders/ring_displace.gdshader`**
(`vertex()` + new uniforms) and the config plumbing in
**`wg-10/rust/src/terrain_view.rs`** (`Wg10TerrainView::configure` → per-tile
`ShaderMaterial` uniforms, via `Wg10ClipmapRings::bind_tile`). **No Rust core
(hash/grammar/height/parity) change; no new GPU compute pass; no page/streaming
change.**

`vertex()` pipeline (new steps marked **NEW**):

```
world    = MODEL_MATRIX * VERTEX                         (existing)
h_fine   = texture(height_tex,  (world.xz - page_origin)/world_span).r   (existing)
h_coarse = texture(coarse_height_tex, (world.xz - coarse_origin)/coarse_span).r (existing)
t        = geomorph LOD blend factor                     (existing)
h_base   = mix(h_fine, h_coarse, t)         ← THE facts/collision height (existing)
──────────────────────────────────────────────────────────────────────
desc     = surface_descriptor(world)        NEW  {slope, curvature, height_band}
d        = fbm_detail(world.xz)             NEW  bounded high-freq, world-space
mod      = modulate(desc)                   NEW  slope/band → [0,1] amplitude scale
fade     = (1.0 - t) * level_detail_scale   NEW  detail → 0 into coarse / morph band
VERTEX.y = (h_base + d * detail_amp * mod * fade) * height_scale
```

**Three hard invariants (the contracts):**
1. **base-untouched** — `h_base` formed before detail; detail only added to
   `VERTEX.y`. ⇒ visible-vs-collision parity unchanged (0.0009 m).
2. **edge-safe** — `d`, `desc` are pure `f(world.xz)`; abutting tiles compute
   identical shared-edge values (existing clamp-to-edge sampler). ⇒ seam = 0.
3. **LOD-safe** — `fade` zeroes detail where the geomorph blends to coarse and on
   coarse levels. ⇒ no morph-fight, no LOD-boundary pop.

## 5. The surface descriptor (the reusable seam)

```glsl
struct SurfaceDescriptor {
    float slope;       // 0=flat, ↑=steeper; |gradient of base height|
    float curvature;   // signed; convex/ridge (+) vs concave/valley (−)
    float height_band; // clamp(h_base / relief_ref, 0, 1); altitude band
};
SurfaceDescriptor surface_descriptor(vec3 world);  // reads the BASE page
```

Computation (cheap, in-shader; texel size = `world_span / page_px`, both known):
- **slope** — finite-difference gradient: sample base page at ±1 texel in X,Z;
  `slope = length(vec2(dh_dx, dh_dz))`. ~4 extra page taps.
- **curvature** — second difference from the same neighbor samples
  (`h_left + h_right − 2·h_center`, both axes). Near-free once neighbors are read.
- **height_band** — `clamp(h_base / relief_ref, 0, 1)`. Free.

Edge-safe: all reads are world-UV with the clamp-to-edge sampler ⇒ descriptor agrees
on tile seams.

**Seam contract:** `surface_descriptor()` is THE function M6 (material blend) and M7
(erosion mask) call. M5 default modulation uses only `slope`; `curvature`/
`height_band` are computed and available (the seam), used by config experiments and
later milestones — extend the function, don't re-derive slope elsewhere.

**Perf note (pillar 2):** the neighbor taps are the main new per-vertex cost
(GRID_RES² × 9 tiles × N levels vertices). Measured by the p99 gate. Known lever if
tight: compute slope from the COARSE page on far levels (detail fades there anyway).
Do NOT pre-optimize — measure first.

## 6. The detail fBm + modulation

```glsl
float fbm_detail(vec2 world_xz) {
    float sum = 0.0, amp = 1.0, freq = detail_freq;
    for (int i = 0; i < detail_octaves; i++) {
        sum  += amp * value_noise(world_xz * freq);
        freq *= 2.0;            // lacunarity = 2
        amp  *= detail_gain;    // gain/persistence (config)
    }
    return sum;                 // |sum| ≤ Σ gain^i  → closed-form ceiling
}

float modulate(SurfaceDescriptor s) {
    // more detail on slopes, less on flats. slope_influence ∈ [0,1] blends
    // uniform (0 = rolling everywhere) ↔ slope-driven (1 = rock on steep only).
    float slope_term = mix(1.0, smoothstep(0.0, slope_ref, s.slope), slope_influence);
    return clamp(slope_term, 0.0, 1.0);
}

// fade = (1.0 - t) * level_detail_scale[level]
//   (1 - t): detail dies exactly where geomorph blends to coarse → no pop.
//   level_detail_scale: finest levels carry full detail, coarse far levels none.
```

- **Bounded:** `detail_amp × Σ gain^i` is a hard, provable displacement ceiling (the
  gate asserts it).
- **The character knob:** `slope_influence` is the rocky↔rolling spectrum (default
  "balanced" ≈ 0.6). Adaptable per pillar 1 with no code change.
- **Default look:** balanced/natural — craggy on steep faces, calm on valley floors,
  believable across all 12 DEM families.

## 7. Config tunables (all validated/clamped — pillar 1 + 4)

Threaded through `Wg10TerrainView::configure` (extending the existing constants in
`m3_review.gd`), passed to per-tile `ShaderMaterial` uniforms:

| Tunable | Meaning | Default (balanced) |
|---|---|---|
| `detail_amp` | peak detail displacement (metres) | tuned in S1, owner-confirmed |
| `detail_freq` | base spatial frequency (1/metre) | tuned to GRID_RES mesh |
| `detail_octaves` | fBm octave count | ~4–5 |
| `detail_gain` | per-octave persistence | ~0.5 |
| `slope_influence` | rocky↔rolling blend ∈ [0,1] | ~0.6 |
| `slope_ref` | slope at which modulation saturates | tuned |
| `level_detail_scale` | per-level detail multiplier (LOD fade) | full→0 over levels |

Validation rejects out-of-range/NaN with a descriptive error (no silent default).

## 8. Verification

Two-layer (gate proves invariants; owner proves the look — DESIGN §7.3). The gate
explicitly does NOT prove "looks good"; STATUS will say so plainly.

**Automated — `m5_detail_check.gd` (m3/m5 suite, WINDOWED):**
1. **Bounded** — detail contribution ≤ closed-form ceiling (`detail_amp × Σ gain^i`).
   No blow-up.
2. **Edge-safe with detail on** — extends the M3 seam test: abutting tiles' shared-
   edge vertices bit-agree WITH detail enabled. seam = 0. (Protects the M3 work.)
3. **Base unchanged** — `facts_collision_parity_check` still 0.0009 m with detail on
   ⇒ detail didn't touch `h_base`.
4. **LOD fade** — detail → 0 on the coarsest level and in the morph band (sampled at
   a level boundary). No detail where it would pop.
5. **Non-vacuous** — detail genuinely present on a fine flat-ish region (variety vs
   detail-off) ⇒ can't pass on a no-op.
6. **p99 < 6 ms @ ~1000 m/s** with detail on (re-run `m3_accept_check` detail-enabled).

**Owner-flown acceptance (the real sign-off):** fly `m3_review.tscn` with a detail
on/off toggle (like the existing M/K keys) and A/B confirm: "has real shape now, not
blobby"; rocky on steep / calm on flats; no shimmer/crawl under motion; no new
seams/LOD pops. Gate-green is necessary, not sufficient.

## 9. Slice plan (prove-one-at-a-time)

Each slice: failing gate → minimal shader/config change → gate green → owner A/B →
commit. Rust core untouched (cargo stays 115); work is in the shader + `terrain_view.rs`
config plumbing + GDScript gate.

- **Slice 1 — fBm in GLSL + uniform detail.** Port value-noise/fBm to the shader;
  bounded world-space detail at flat amplitude (no modulation/fade) behind
  `detail_amp`. Gate: **bounded + edge-safe-with-detail (the seam test, proven FIRST
  — riskiest invariant) + base parity unchanged.** Owner A/B: "terrain has texture."
  *Retires the core risk.*
- **Slice 2 — LOD fade.** `fade = (1−t) × level_detail_scale`. Gate: detail → 0 on
  coarsest + in morph band; no new LOD pop. Owner A/B: "no shimmer/pop at boundaries
  at speed."
- **Slice 3 — surface descriptor + slope modulation.** Add `surface_descriptor()` +
  `modulate()`. Gate: descriptor edge-safe; detail concentrates on slopes (flat
  regions get less); non-vacuous. Owner A/B: "rocky where steep, calm on flats." *The
  reusable seam lands here.*
- **Slice 4 — config + p99 + docs.** Thread all tunables through `configure()` with
  validation/clamping (reject bad config); re-run `m3_accept_check` detail-on for the
  **p99 < 6 ms** sign-off; audit vs the four pillars; update DESIGN/ROADMAP/STATUS +
  HANDOFF. Owner: final acceptance fly.

**Slice ordering rationale:** scariest invariant (reopened seams) proven in S1; perf
is the LAST gate once all ALU is present (measure the real cost); the general
descriptor seam lands only after the specific cheap detail works (pillar-minimal, but
the seam is there).

## 10. Risks & mitigations

- **Reopened seams** (the M3 blood) → world-space-pure detail + S1 seam gate first.
- **p99 regression** from descriptor taps → measured last (S4); known lever =
  coarse-page slope on far levels; do not pre-optimize.
- **Detail shimmer/crawl under motion** → LOD fade (S2) + frequency tuned to mesh
  density; owner A/B is the judge.
- **Detail finer than mesh invisible** → expected; documented as M6 normal-map's job,
  not chased with tessellation.
- **Config blow-up** → validation/clamping + bounded-ceiling gate.

## 11. Definition of done (DESIGN §7.3)

- `m5_detail_check` green (all 6 invariants); `m3_accept_check` p99 < 6 ms detail-on;
  fast/gpu/m3 suites still green; cargo unchanged (115).
- Owner acceptance fly confirms the look (rocky/calm, no shimmer, no seams/pops).
- `surface_descriptor()` documented as the M6/M7 seam.
