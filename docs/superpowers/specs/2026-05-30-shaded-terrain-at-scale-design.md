## 1. Purpose & the measurable target

WG10's terrain reads as "a heightmap, not real terrain" (owner fly, 2026-05-30). This milestone closes
that to the **WG9 "looks-alright-without-much-tuning" baseline**, which we reverse-engineered from WG9's
actual code this session (WG9 is READ-ONLY reference):

| Dimension | WG9 (the "alright" baseline) | WG10 NOW | This milestone targets |
|---|---|---|---|
| Near-field mesh spacing | ~16 m (2048 m chunk / 129 verts) | **128 m** (8192/64) | WG9-class ~16–32 m near |
| Per-family relief | 190–640 m (`relief_scale_m`) | **~990–2765 m** (dem_v1) | ~200–640 m visible |
| Shading | computed normals + lighting (`build_normals`) | **`unshaded` debug height-color** | analytic normals + basic lit material |

**The bet (grounded in the owner's "WG9 looked alright without a ton of tuning"):** those three together
= the WG9 baseline, and they are COUPLED — normals need a finer mesh to mean anything; lighting needs sane
relief to shade believably. WG9 did all three in ONE surface builder; so do we, as one milestone.

**Definition of done:** an owner fly reads as "this looks like terrain, roughly WG9-alright" (lit,
sane-relief, finer-mesh shapes), NOT "a heightmap" — with the hardened GPU gate confirming budget.

## 2. Scope

**IN (the minimal WG9 baseline):**
- **Mesh density** — tune `BASE_SPAN`/`GRID_RES`/`NUM_LEVELS` (existing config) to WG9-class near density.
- **Relief multiplier** — one `relief_scale` knob on the height field, render + collision in lockstep.
- **Basic normals + lighting** — analytic normals from the page gradient, slope/height albedo ramp, the
  existing directional light; replace the `unshaded` debug color (kept behind a toggle).
- Tune M5 detail amplitude to WG9-modest (~20–60 m) once there's shading + scale to judge it against.

**OUT (YAGNI — later milestones):**
- Rich materials / texture splatting / PBR / biome-driven material packs → the FULL M6 (this is only
  basic lit normals, the baseline).
- M7 erosion / hydrology (carving drainage).
- **Data-source relief rescale** (editing 115 pack `relief_m` values + re-baselining parity fixtures) →
  available as a future option; this milestone uses a render+facts MULTIPLIER instead (reversible,
  live-tunable, leaves relative family relief intact).
- New M5 detail features (the detail SEAM exists from M5 S1; we only tune its amplitude here).

## 3. The four pillars

1. **Adaptable/tunable** — every lever is config: `relief_scale`, `BASE_SPAN`/`GRID_RES`/`NUM_LEVELS`,
   albedo-ramp bands, light. No magic numbers; the WG9-class values are *found* on the gate, then set as
   config defaults.
2. **Performance** — mesh density is the ONE budget-sensitive lever (where WG9 died). Tuned EMPIRICALLY
   on the hardened real-GPU-time gate (`m5_perf_hardened_check`), perf-gated LAST when all cost is present.
   Shading is cheap (analytic normals + one light); relief is free (a multiply).
3. **Quality** — visible==collision parity PRESERVED (relief_scale applies to both); raw `height()` parity
   formula UNTOUCHED; edge-safe normals (no lighting seam). No collapse.
4. **No shortcuts** — relief is a real height-field scale honoring collision (not a render-only fake that
   would re-open the visible-vs-collision divergence M4 closed); validated config.

## 4. Component 1 — Mesh density (finer near-field)

`Wg10ClipmapRings` is a clipmap: `GRID_RES` verts per tile, tile span = `BASE_SPAN · 2^level` (doubles per
level). So the NEAR ring is finest, far rings coarse-per-span — fine-near/coarse-far is structural (the
deliberate anti-WG9-perf design). Levers (all existing `configure()` params — **no Rust change**):
- **`GRID_RES`** 64 → 128/256 (densifies every level proportionally; far tiles same vert count, huge span).
- **`BASE_SPAN`** 8192 → e.g. 2048 (WG9's chunk) so level-0 spacing = 2048/64 = 32 m, or 2048/128 = 16 m
  (exactly WG9). Add `NUM_LEVELS` to keep far reach.

**Approach:** find the config giving WG9-class near density (~16–32 m) that holds real GPU p99 < 6 ms,
EMPIRICALLY on the hardened gate. Instinct: lower `BASE_SPAN` toward WG9's 2048 + modest `GRID_RES` is
closer to WG9's proven config than brute `GRID_RES=256` on 8192 spans — but the gate decides.

**Honest constraint:** finer mesh = smaller spans = MORE pages stream under motion (more page-compute
pressure). The hardened gate's `stream_events` + GPU p99 + page budget all re-checked; if finer near
density blows the streaming budget, balance via NUM_LEVELS / CAPACITY (a real finding, not a silent cap).

## 5. Component 2 — Relief multiplier (render + collision in lockstep)

Bring visible relief to WG9 range WITHOUT editing pack data or disturbing parity fixtures, keeping
visible==collision exact.

- **One `relief_scale` config value** (e.g. ~0.25: ~2765 m → ~690 m) applied to the **`base` height term at
  the single consume point.** `Wg10Facts.get_height` = `clamp(base + edit_delta, bedrock, ceiling)` with
  `base = height(x,z) · relief_scale`. Both the render displacement AND facts/collision derive from this
  scaled base → **visible == collision automatically** (the 0.0009 m contract holds; both scale identically).
- **Raw `height()` parity (M2) UNTOUCHED:** `relief_scale` is applied AFTER `height()`, as a uniform
  multiplier on BOTH CPU and GPU outputs. The raw-formula parity fixtures stay valid; the render shader
  multiplies its sampled page height by `relief_scale` (new uniform); facts multiply `height()` by it.
- **Folds in the existing `HEIGHT_SCALE=0.35`:** to avoid two confusingly-overlapping scales, `relief_scale`
  becomes the ONE authoritative world-relief knob (applied to the height field, affecting collision);
  the old pure-display `HEIGHT_SCALE` is subsumed.
- **Why a multiplier not pack edits:** reversible, live-tunable (fly to find the WG9 feel), one value vs
  115, preserves relative family relief character. Data-source rescale stays a future option.

## 6. Component 3 — Normals + basic lighting (the "looks like terrain" lever)

The part the owner's fly reacted to. WG9 proved it's most of the "alright" win.

- **Drop `render_mode unshaded`** in `ring_displace.gdshader` → the surface receives the scene's
  `DirectionalLight3D` (already in `m3_review`).
- **Analytic normal from the page gradient** — sample the base page at ±1 texel (the SAME finite-difference
  we specced for M5 S3's `surface_descriptor` — this seam pays off here) → gradient → normal. No baked
  per-vertex normals, no extra data, resolution-independent. The M5 detail fBm ALSO perturbs the normal, so
  **detail finally READS under lighting** (the thing it couldn't do unshaded).
- **Basic lit material:** `NORMAL` from the computed gradient; `ALBEDO` from a simple slope/height ramp
  (grass-low / rock-steep / snow-high — the classic); Godot's lighting does the rest.
- **Edge-safe:** normals computed from world-position page samples with the clamp sampler → abutting tiles
  match at the seam (no lighting seam).
- **Keep `wg_dbg_mode`** height-color behind its toggle (debug), default OFF → lit terrain.
- **YAGNI:** basic lit shading ONLY — no texture splatting, no PBR packs, no biome materials (later full M6).

## 7. Verification

Two layers (gate proves invariants; owner proves the look — DESIGN §7.3).

**Automated gates:**
- **Hardened GPU perf** (`m5_perf_hardened_check`, built): real GPU p99 < 6 ms with finer mesh + shading
  ON + did-real-work asserts. The instrument that makes density tuning honest.
- **Visible==collision parity:** extend `facts_collision_parity_check` to assert parity WITH `relief_scale`
  applied (both sides scale → still ~0.0009 m).
- **Raw `height()` parity** (existing gpu suite): unchanged → formula untouched.
- **Edge-safe normals:** extend the seam check — abutting tiles' edge normals match (no lighting seam).

**Owner-flown acceptance (the bar):** fly `m3_review.tscn` → reads as "WG9-alright terrain, not a
heightmap." A/B toggles per part (detail N-key exists; add relief-scale + shading toggles).

## 8. Slice plan (prove-one-at-a-time, each gated + flyable)

- **Slice 1 — Relief scale.** Add the single `relief_scale` knob (render + facts in lockstep, fold in
  `HEIGHT_SCALE`). Gate: visible==collision parity holds with scaling; raw parity untouched. Owner A/B:
  "sane-height terrain, not 2.7 km spikes." *Smallest; de-risks the parity-sensitive part first, isolated.*
- **Slice 2 — Normals + basic lighting.** Drop `unshaded`; analytic normals from the page gradient;
  slope/height albedo ramp; keep debug toggle. Gate: edge-safe normals (no lighting seam); perf still green.
  Owner A/B: "it's lit/shaded now, reads as terrain." *The big looks-real lever.*
- **Slice 3 — Mesh density tuning.** Empirically tune `BASE_SPAN`/`GRID_RES`/`NUM_LEVELS` toward WG9-class
  near density, measured on the hardened GPU gate (finest that fits 6 ms; streaming budget holds). Owner A/B:
  "shapes are crisp/fine, not blobby." *Perf-gated LAST when all cost is present.*
- **Slice 4 — Integrate + tune + docs.** All three on; tune M5 detail amplitude to WG9-modest (~20–60 m)
  now that shading + scale exist to judge it; owner acceptance fly = "WG9-alright"; audit vs pillars;
  update living docs.

**Order rationale:** relief (parity-sensitive) first while isolated → normals (the look win) → mesh density
(perf-sensitive) gated last with all cost present → integrate + detail-tune.

## 9. Risks & mitigations
- **Finer mesh blows GPU/stream budget** → measured on the hardened gate each density step; balance via
  NUM_LEVELS/CAPACITY; the gate's did-real-work asserts prevent a false "cheap because empty" pass.
- **Relief_scale breaks visible==collision** → applied at the single consume point so both scale identically;
  the extended parity gate asserts it.
- **Normals reopen a seam** → world-position-pure + clamp sampler; seam-normal gate.
- **Two relief knobs fight** (`relief_scale` vs `HEIGHT_SCALE`) → fold HEIGHT_SCALE into relief_scale (one knob).
- **Coarse-mesh normals shade facets** → that's WHY mesh density is in-scope (Slice 3); normals on the finer
  mesh is the combination WG9 proved.

## 10. Definition of done (DESIGN §7.3)
- Hardened GPU gate green (p99 < 6 ms) at the chosen WG9-class density with shading on; visible==collision
  parity green with relief_scale; raw parity + fast/cargo unchanged.
- Owner acceptance fly: "WG9-alright terrain, not a heightmap."
- `relief_scale` is the one authoritative relief knob; `surface_descriptor` gradient reused for normals.
- DESIGN/ROADMAP/STATUS + HANDOFF updated; spec committed (this file).
